# char_baker_cat 리비전 발주 (rev2)

기존 `char_baker_cat.blend` (1,340 tris, 높이 1.64m)를 아래 항목대로 수정한다.
**리깅·애니메이션은 이번 작업 범위가 아님** — 정적 모델 품질만 끌어올린다.
기존 스펙(1유닛=1m, 키 약 1.6m, 피벗 발바닥, 정면 -Y, 3,000 tris 이하, 단일 팔레트 재질)은 그대로 유지한다.

## 수정 항목

### 1. 모자 밀착 (떠 보임 제거)
- 현재 제빵모자 챙과 머리 사이에 틈이 보인다. 모자를 아래로 내려 **챙 하단이 몸통 상단에 살짝 파묻히게**(1~2cm 오버랩) 배치할 것. 어느 각도에서 봐도 모자와 머리 사이로 배경이 보이면 안 된다.
- 컨셉 4면도(`char_baker_cat_turnaround_v1.png`)의 모자 크기·비율을 기준으로 실루엣을 맞춘다.

### 2. 귀 대칭·형태 수정
- 현재 한쪽 귀가 접힌 판처럼 형태가 무너져 있고 좌우 모양이 다르다.
- 귀는 **하나를 만들어 미러링**해서 좌우가 완전히 대칭이 되게 할 것. 형태는 컨셉처럼 납작한 삼각형(안쪽 분홍 면 포함).
- 위치: 몸통 상단 좌우, 모자 챙 바로 아래에서 바깥으로 솟는 형태. 귀가 모자 메시를 뚫고 지나가는 클리핑이 없어야 한다 (모자 챙을 귀 위쪽에서 시작하거나, 귀를 챙 앞/옆으로 빼서 해결).

### 3. 얼굴을 지오메트리 → 텍스처로 전환
- 현재 눈·코·입·수염이 별도 메시 조각으로 붙어 있다. 전부 삭제하고 **팔레트 텍스처(128×128)에 얼굴을 그려서 몸통 UV에 입힐 것.**
- 몸통 정면 상단부에 얼굴 전용 UV 영역을 할당하고, 컨셉 4면도의 얼굴(점 눈 2개, 코, ω 입, 좌우 수염 3가닥)을 텍스처에 재현한다.
- 나머지 색 영역(몸통·모자·앞치마·바게트·팔다리)은 기존처럼 플랫 컬러 블록으로 유지.
- 효과: 삼각형 수 감소 + 어느 거리에서나 얼굴이 또렷하게 보임.

### 4. 바게트 한 손 파지로 변경
- 현재 몸 앞에 가로로 안고 있는 포즈를, **오른손으로 자루 쥐듯 한 손 파지**로 변경 (다음 단계의 휘두르기 애니메이션 대비).
- 바게트는 독립 오브젝트로 유지하고 오브젝트 이름 `prop_baguette`로 지정. 왼팔은 자연스럽게 내린 자세.

### 5. 마무리 정리
- 모든 오브젝트 트랜스폼 적용 (location 0 / rotation 0 / scale 1), 임시·히든 오브젝트 삭제.
- 몸통 메인 컬러가 `#F2CC80` 계열인지 확인.

## 납품물
1. `char_baker_cat.blend` (수정본)
2. `char_baker_cat.fbx` — **정적 메시 익스포트** (Forward: -Z Forward, Up: Y Up, Apply Scalings: FBX All). 리깅 없어도 FBX는 뽑을 것 — Unity 임포트 테스트용.
3. `char_baker_cat_palette.png` (얼굴 포함된 갱신본)
4. 프리뷰 렌더 4장: 정면 / 좌측면 / 후면 / 쿼터뷰 (모자 틈·귀 대칭 확인용)
5. `build_char_baker_cat.py` 갱신본
