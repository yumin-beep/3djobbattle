# char_baker_cat 리깅 + 애니메이션 발주 (rev3)

작업 원본: `Art/Models/char_baker_cat_round_xy_v12.blend` (정적 모델 확정본)
목표: 이 모델에 심플 릭과 애니메이션 3개를 붙여 Unity(Generic 릭)에서 바로 쓸 수 있는 FBX로 납품한다.
메시 형태·색·비율은 절대 수정하지 말 것 — 이번 작업은 리깅과 애니메이션만이다.

## 1. 릭(아마추어) 구조

본 이름과 계층을 정확히 이 구조로 만든다 (총 8개, Y축이 정면 기준):

```
root            (원점 0,0,0 — 항상 고정, 애니메이션 키 넣지 말 것)
└─ body         (몸통 하단 중심 — 몸통·모자·귀·얼굴이 따라옴)
   ├─ arm.L     (왼팔 어깨 관절)
   ├─ arm.R     (오른팔 어깨 관절)
   │  └─ prop   (바게트 — 오른손 위치)
   ├─ leg.L     (왼다리 고관절)
   └─ leg.R     (오른다리 고관절)
```

## 2. 스키닝 — 리지드 바인딩 (중요)

- **부드러운 웨이트 금지.** 각 메시 파츠를 담당 본에 **100% 웨이트로 통짜 바인딩**한다:
  - 몸통·모자·귀 → `body` / 왼팔 → `arm.L` / 오른팔 → `arm.R` / 바게트 → `prop` / 왼다리 → `leg.L` / 오른다리 → `leg.R`
- 이 스타일(콩 몸통 + 막대 팔다리)은 관절이 접히는 게 아니라 파츠가 통째로 흔들리는 게 정답이다. 자동 웨이트(Automatic Weights) 쓰지 말 것 — 버텍스 그룹에 직접 1.0 할당.
- 검증: 포즈 모드에서 각 본을 회전시켰을 때 담당 파츠만 통째로 따라오고, 남는 버텍스(안 따라오는 점)가 하나도 없어야 한다.

## 3. 애니메이션 3개

공통 규칙: **30fps**, 제자리 애니메이션(root motion 없음 — `root` 본은 절대 움직이지 않는다), 액션 이름 정확히 지정.

### `Idle` — 45프레임(1.5초) 루프
- `body`가 위아래로 살짝(±2cm) 숨쉬기 봉긋거림 + 아주 미세한 좌우 기울기(±1.5°)
- 팔이 몸 옆에서 미세하게 흔들림
- 첫 프레임과 마지막 프레임 포즈 동일 (끊김 없는 루프)

### `Run` — 18프레임(0.6초) 루프
- 다리 앞뒤 스윙 ±35°, 좌우 교차
- 팔은 다리와 반대 위상으로 ±25° 스윙 (바게트 든 오른팔은 ±15°로 작게)
- `body` 앞으로 8° 기울기 + 스텝마다 위아래 바운스(±4cm) + 좌우 롤 ±3°
- 통통 뛰는 귀여운 종종걸음 느낌. 루프 끊김 없어야 함

### `Attack` — 12프레임(0.4초) 단발
- 프레임 1–4: `arm.R`(+prop)을 뒤로 들어올리는 와인드업
- 프레임 5–8: 바게트를 몸 앞으로 가로지르며 120° 호를 그리는 스윙, `body`도 스윙 방향으로 10° 따라 회전
- 프레임 9–12: 원래 자세로 복귀
- 마지막 프레임 = Idle 기본 포즈와 동일 (게임에서 Attack 후 Idle로 자연스럽게 이어짐)

## 4. 익스포트

- 세 액션을 모두 **NLA 스태시(Push Down)** 하여 FBX에 전부 포함시킬 것.
- 파일명: **`char_baker_cat_rigged.fbx`**
- Blender FBX 설정: Forward = -Z Forward, Up = Y Up, Apply Scalings = FBX All, Bake Animation 켜기, Add Leaf Bones **끄기**
- 기존 규칙 유지 확인: 1유닛=1m, 키 약 1.6m, 피벗 발바닥, 팔레트 텍스처 1장
