# 현대 직업대전 — 캐릭터 3D 발주 스펙 v1

이 문서를 그대로 AI(또는 외주자)에게 전달한다. 결과물은 Unity 6 (URP) 게임에 통합된다.

## 1. 아트 스타일

- **체형**: 세로로 긴 콩(강낭콩/캡슐) 모양 몸통 하나가 캐릭터의 전부다. 머리와 몸이 분리되어 있지 않다.
- **얼굴**: 몸통 표면에 붙은 납작한 도형들 — 작은 점 눈, 단순한 부리/코/입, 필요하면 눈썹. 디테일한 이목구비 금지.
- **팔다리**: 아주 가는 막대(스틱) 형태. 손가락 없음, 발은 작은 덩어리 하나.
- **색**: 아웃라인 없는 플랫 컬러. 그라데이션·PBR 질감·노멀맵 금지. 러프니스 높게(무광).
- **직업 표현**: 소품 1~2개로만 표현 (모자, 앞치마, 도끼 등). 소품은 실제보다 과장되게 크게.
- 전체적으로 귀엽고 뭉툭한 인디게임 캐주얼 룩. 쿼터뷰(위에서 비스듬히)로 멀리서 보이므로 실루엣과 색 대비가 최우선.

참고 스타일 서술(이미지 생성/모델링 프롬프트용):
"chubby bean-shaped animal character, single capsule body with face directly on the body, tiny stick limbs, flat solid colors, no outlines, minimal facial features, cute low-poly indie game style, matte unlit look"

## 3. 기술 사양 (반드시 준수)

### 치수·축
- **1 unit = 1 m.** 캐릭터 전체 높이(소품 제외) **1.6 m**, 몸통 최대 폭 약 0.9 m.
- **피벗(원점) = 발바닥 중앙** (0, 0, 0). 캐릭터는 지면 위에 서 있는 상태.
- **정면**: Blender에서 -Y 방향(정면 뷰 Numpad 1에서 카메라를 바라봄). FBX 익스포트 후 Unity에서 +Z를 바라봐야 한다.
- 모든 오브젝트 트랜스폼 적용 완료 상태 (location 0, rotation 0, scale 1).

### 메시·머티리얼
- 폴리곤 예산: 캐릭터당 **3,000 삼각형 이하** (소품 포함).
- 머티리얼 **1개**, 텍스처는 **128×128 이하 플랫 팔레트 PNG 1장** (UV로 색 영역 지정). 버텍스 컬러 사용 금지 (URP 기본 셰이더에서 안 보임).
- 모디파이어 전부 적용, 히든/임시 오브젝트 삭제.

### 리깅·애니메이션
- 심플 릭: 몸통(root/hips), 팔×2, 다리×2, 소품 본 — **본 15개 이하** 권장. Unity에서 Generic 릭으로 사용한다 (휴머노이드 호환 불필요).
- 애니메이션 클립 (이름 정확히):
  - `Idle` — 숨쉬기/까딱거림, 1~2초 루프
  - `Run` — 종종걸음, 0.5~0.8초 루프. 몸통이 앞으로 살짝 기울고 좌우로 흔들리면 좋음
  - `Attack` — 소품 휘두르기/쏘기, 0.3~0.5초 단발
  - (선택) `Hit`, `Death`
- 모든 클립은 제자리 애니메이션 (root motion 없음 — 이동은 게임 코드가 처리).

### 납품물 (캐릭터당)
1. `char_xxx.fbx` — 메시+릭+애니메이션 포함 (Blender FBX 익스포트: Forward = -Z Forward, Up = Y Up, Apply Scalings = FBX All, Bake Animation 켜기)
2. `char_xxx_palette.png` — 팔레트 텍스처
3. `char_xxx.blend` — 원본
4. 정면/측면 프리뷰 렌더 PNG

## 4. 검수 기준 (통과 못 하면 반려)

- [ ] Unity에 FBX 임포트 시 스케일 1로 높이 약 1.6 m
- [ ] 캐릭터가 +Z를 바라봄, 발이 y=0에 닿음
- [ ] 머티리얼 1개 + 팔레트 텍스처 연결만으로 색이 올바르게 보임
- [ ] Idle/Run/Attack 클립이 이름 그대로 존재하고 루프 자연스러움
- [ ] 삼각형 수 3,000 이하
